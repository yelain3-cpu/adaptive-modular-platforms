# Application-friendly project summary (draft for owner review)

## 45-second narrative

**Problem.** The project investigated how Tai O’s historic stilt-house communities might adapt to changing water levels and human loads while preserving local architectural identity.

**Design and prototype.** Working with teammate Zhou Yiheng under instructor Professor Kaicong Wu, I helped develop a modular responsive floating platform with two demonstrated interactions: force-responsive pneumatic elements and ultrasonic-sensor-informed kinetic façade movement. We used Arduino, Grasshopper, Python components and a course-provided communication framework. The project was entered in Innovation A (EC-042) of the 11th Hong Kong University Student Innovation and Entrepreneurship Competition and received a Merit Prize (per my CV/project records).

**My technical development.** I contributed Arduino programming and project-specific parameter-control logic. The surviving archive includes force-control sketches and the Grasshopper definition, although the exact source-to-actuator path for the final façade demonstration has not been reconstructed from all files.

**Continuing learning (2026 extension).** I am using Python to explore a separate, software-only simulation of responsive control. This extension uses new illustrative rules and AI-assisted coding; I will only claim features and tests that I can personally run, understand, and explain.

## What this project demonstrates to admissions reviewers

- Motivated learning by moving from design problems to tangible control logic and code.
- Physical computing experience with sensors, actuator outputs and serial communication.
- Collaboration, project coordination, and iterative prototyping.
- Awareness of limitations, evidence quality and technical attribution.

## What it does **not** claim

- Advanced artificial intelligence or machine learning in the 2025 prototype.
- Independent authorship of the Firefly Firmata foundation or AI-generated communication components.
- Deployment in Tai O, hardware-calibrated pressure control, measured flood-protection performance, production reliability or safety certification.
- That the new simulator has already been run or extended by the project owner before they test it.
