# Arduino sketches — historical source

All `.ino` files in this directory are unchanged from the uploaded student project. They represent versions and experiments rather than a single verified final firmware build.

- **`force-control/20250209_Force_v2.ino`**: simple force-threshold pneumatic controller.
- **`force-control/20250211_Force_v4.ino`**: force-threshold control with extra counters and one-byte serial input.
- **`force-control/VVS_1.ino`**: alternate force-controller variant.
- **`experiments/sketch_feb9a.ino`**: timed pneumatic cycling.

The uploaded `sketch_feb12a.ino` was an exact duplicate of v2, so it is documented in `../docs/SOURCE_INVENTORY.md` but not separately included. The supplied Firefly Firmata template and its course-modified derivative are excluded while reuse permission is unclear. **Do not upload these sketches blindly to live hardware**; refer to [reproduction notes](../docs/REPRODUCIBILITY.md).
